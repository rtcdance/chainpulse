# ChainPulse 项目规则

本文档定义了 AI 在开发本项目时必须遵循的规则和约束。

## 项目概述

ChainPulse 是一个企业级 Web3 区块链事件索引系统，采用 Go 语言开发，支持单体和微服务两种部署模式。

## 核心原则

### 1. 架构原则
- **DDD 分层**: 严格遵循 domain/application/infrastructure 分层
- **依赖倒置**: 所有外部依赖通过接口隔离
- **插件化**: 核心逻辑与具体实现解耦

### 2. 代码原则
- **简洁**: 不过度设计，保持代码简单
- **可测试**: 所有核心逻辑必须有单元测试
- **可观测**: 关键操作必须有日志和指标

### 3. 安全原则
- **零信任**: 不信任任何外部输入
- **最小权限**: 只授予必要的权限
- **审计追踪**: 敏感操作必须记录审计日志

## 目录结构规范

```
chainpulse/
├── cmd/                    # 入口程序
│   ├── monolithic/         # 单体模式入口
│   └── microservices/      # 微服务模式入口
├── pkg/                    # 公共包
│   ├── core/               # 核心领域
│   ├── plugins/            # 插件实现
│   ├── services/           # 业务服务
│   └── infrastructure/     # 基础设施
├── docs/                   # 文档
├── scripts/                # 脚本
├── test/                   # 测试
└── .trae/skills/           # AI 技能定义
```

## 命名约定

| 类型 | 规则 | 示例 |
|------|------|------|
| 包名 | 小写单词 | `indexer`, `puller` |
| 接口 | 动词+er | `Indexer`, `Puller` |
| 结构体 | 名词 | `Block`, `Event` |
| 函数 | 动词开头 | `ProcessBlock`, `GetEvent` |
| 常量 | 大写蛇形 | `MAX_RETRIES`, `DEFAULT_TIMEOUT` |
| 错误 | Err前缀 | `ErrBlockNotFound` |

## 禁止事项

### 代码层面
- ❌ 禁止全局变量
- ❌ 禁止硬编码配置
- ❌ 禁止忽略错误
- ❌ 禁止裸返回
- ❌ 禁止深层嵌套（>3层）

### 安全层面
- ❌ 禁止提交密钥
- ❌ 禁止日志输出敏感信息
- ❌ 禁止使用明文存储密码

### 架构层面
- ❌ 禁止循环依赖
- ❌ 禁止跨层调用
- ❌ 禁止业务逻辑泄露到基础设施层

## 必须事项

### 代码层面
- ✅ 必须处理所有错误
- ✅ 必须使用 context 进行取消
- ✅ 必须添加有意义的错误信息
- ✅ 必须编写单元测试

### 文档层面
- ✅ 必须更新相关文档
- ✅ 必须添加必要的注释（仅限复杂逻辑）

### 安全层面
- ✅ 必须验证所有输入
- ✅ 必须使用参数化查询
- ✅ 必须限制资源使用

## 技术栈

| 类别 | 技术 |
|------|------|
| 语言 | Go 1.21+ |
| 区块链 | go-ethereum |
| 数据库 | PostgreSQL / MongoDB |
| 缓存 | Redis |
| 消息队列 | Kafka / Redis / ZeroMQ |

| 配置 | viper |
| 追踪 | opentelemetry |
