# ChainPulse AI 开发约束清单

本文档定义了 AI 在开发过程中必须检查和遵守的约束清单。

## 开发前检查

### 需求理解
- [ ] 明确任务目标
- [ ] 确认技术方案
- [ ] 评估影响范围
- [ ] 检查依赖关系

### 设计检查
- [ ] 是否符合 DDD 分层
- [ ] 是否需要新接口
- [ ] 是否影响现有功能
- [ ] 是否需要数据库迁移

## 开发中检查

### 代码质量
- [ ] 遵循命名规范
- [ ] 正确处理错误
- [ ] 添加必要日志
- [ ] 使用 context 传递

### 安全检查
- [ ] 无硬编码密钥
- [ ] 输入已验证
- [ ] SQL 使用参数化
- [ ] 敏感数据已脱敏

### 性能检查
- [ ] 无内存泄漏
- [ ] 无阻塞操作
- [ ] 合理使用缓存
- [ ] 批量处理优化

## 开发后检查

### 测试检查
- [ ] 单元测试通过
- [ ] 覆盖率达标 (>80%)
- [ ] 边界条件测试
- [ ] 错误场景测试

### 文档检查
- [ ] API 文档更新
- [ ] README 更新
- [ ] 注释清晰准确

### 代码审查
- [ ] 无重复代码
- [ ] 无过度设计
- [ ] 无安全漏洞
- [ ] 无性能问题

## 提交前检查

### Git 检查
- [ ] 使用规范提交信息
- [ ] 无敏感信息提交
- [ ] 无无关文件提交
- [ ] 分支命名正确

### 构建检查
- [ ] 编译通过
- [ ] 静态检查通过
- [ ] 测试通过
- [ ] 文档生成成功

## 禁止操作清单

### 代码禁止
- ❌ 禁止删除现有测试
- ❌ 禁止修改公共接口签名
- ❌ 禁止添加未使用的代码
- ❌ 禁止提交调试代码

### 配置禁止
- ❌ 禁止修改默认配置值
- ❌ 禁止硬编码环境变量
- ❌ 禁止提交本地配置

### 数据禁止
- ❌ 禁止删除数据库迁移
- ❌ 禁止修改已有表结构
- ❌ 禁止删除已有索引

## 强制操作清单

### 代码强制
- ✅ 必须处理所有错误
- ✅ 必须使用 context
- ✅ 必须添加日志
- ✅ 必须编写测试

### 安全强制
- ✅ 必须验证输入
- ✅ 必须限制资源
- ✅ 必须记录审计

### 文档强制
- ✅ 必须更新 CHANGELOG
- ✅ 必须更新 API 文档

## 风险评估

### 高风险操作
需要人工确认：
- 修改核心接口
- 修改数据库结构
- 修改配置格式
- 修改部署流程

### 中风险操作
需要代码审查：
- 添加新依赖
- 修改业务逻辑
- 修改错误处理

### 低风险操作
可自动处理：
- 添加新测试
- 修复文档错误
- 优化代码格式

## 异常处理

### 编译失败
1. 检查语法错误
2. 检查导入路径
3. 检查依赖版本
4. 检查 Go 版本

### 测试失败
1. 分析失败原因
2. 检查测试数据
3. 检查环境配置
4. 检查依赖状态

### 静态检查失败
1. 修复代码风格
2. 修复潜在问题
3. 添加必要注释
4. 处理警告信息
