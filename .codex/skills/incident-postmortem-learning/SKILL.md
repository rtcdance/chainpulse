# Skill: incident-postmortem-learning

## Trigger

Use this skill for production bugs, data inconsistencies, outages, and high-severity regressions.

## Must Do

1. Capture incident timeline and blast radius.
2. Identify root cause and contributing factors.
3. Add regression tests to prevent recurrence.
4. Add monitoring/alerting improvements.
5. Record concrete corrective actions with owners and due dates.

## Must Not

- No "fixed only" closure without root cause evidence.
- No incident closure without regression safeguards.

## Exit Criteria

- Root cause documented.
- Preventive tests and telemetry improvements merged.
- Follow-up actions tracked.
