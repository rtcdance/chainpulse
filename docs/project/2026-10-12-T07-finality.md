# T07 交付：finality

> 对应任务：`docs/specs/2026-10-12-web3-go-backend-delivery-plan.md` §5 的 **T07 / P0 / 6h**。
> 状态：**In Progress** —— bool 接口的降级语义与显式 confidence/source/observed_at 已完成并用真实 HTTP 桩验证；
> 调用方改造、provider 分歧检测、前端呈现 unknown/degraded 未做。
> 日期：2026-10-12，Asia/Singapore。

---

## 1. 缺陷（读码确认，两处独立）

`pkg/services/finality/finality_checker.go`：

**① `IsBlockFinalized`（bool 兼容接口）无视降级** —— 第 164 行：

```go
return result.IsFinalized, nil   // 即使 result.Degraded == true
```

而 `IsFinalized = blockNumber <= finalized`。`finalized` 在"标签不支持"时**已退到 `latest`**（第 122 行）⇒ **一个 latest 回退的高度会被当成 finalized 返回 `true`**，调用方据此**错误晋升事件**。

**② L2 的 `safe` 被当成 finalized** —— 第 99 行 L2 用 `tag = "safe"`，但 `degraded` **保持 false**（第 114 行只在 fallback 分支置 true）⇒ 从 `safe` 得到的答案被当作"有 finality 保证"。**违反 `safe ≠ finalized`。**

这正是 F08："用 L2 `safe` 近似 finalized、失败时退到 latest；bool 接口仍按高度返回真"。

---

## 2. 实现

### 2.1 显式 confidence / source / observed_at

新增两个枚举与三个字段：

| `FinalityConfidence` | 含义 |
| --- | --- |
| `unknown` | 无可用答案 |
| `degraded` | 来自 `latest` 回退 ⇒ **无 finality 保证** |
| `safe` | 来自 `safe` 标签 ⇒ **不是 finalized** |
| `finalized` | 来自 `finalized` 标签 ⇒ **唯一可晋升的来源** |

| `FinalitySource` | 取值 |
| --- | --- |
| `finalized_tag` / `safe_tag` / `latest_fallback` / `unknown` | 来源可追溯 |

`FinalityResult` 现含 `Confidence` / `Source` / `ObservedAt`（缓存写入时间，供调用方判断新鲜度）/ `FinalizedBlockNumber`（判决所依据的高度）。

### 2.2 判决规则

- `GetFinalizedBlockNumber`：按标签设置 `source`/`confidence`；**`safe` 与 `latest` 回退都置 `degraded = true`**，但用 `confidence` 区分二者。
- **`IsBlockFinalized`：仅当 `Confidence == finalized` 且未降级才返回 `true`**；否则返回 `false`（不再看高度）。
- `IsBlockFinalizedWithStatus`：把 `confidence`/`source`/`observed_at`/`finalized_block_number` 一并返回。

## 3. 验收（单元 3 个，真实 HTTP 桩，全 PASS）

| 测试 | 场景 | 断言 |
| --- | --- | --- |
| `TestIsBlockFinalizedRefusesDegraded` | L1 的 `finalized` 标签不支持 ⇒ 退到 `latest`（高度 1000） | 查 block **1** ⇒ `IsBlockFinalized` **false**（旧代码返回 true）；`Confidence=degraded`、`Source=latest_fallback`、`ObservedAt` 非零 |
| `TestSafeIsNotFinalized` | L2（Arbitrum）走 `safe` 标签 | `IsBlockFinalized` **false**；`Confidence=safe`、`Source=safe_tag`、`Degraded=true` |
| `TestFinalizedTagPromotesOnlyBelowHeight` | L1 正常 `finalized`（高度 1000） | 999 ⇒ **true**（`Confidence=finalized`、未降级）；1001 ⇒ false |

> 第一条是关键：**高度完全支持"已 final"，但来源降级 ⇒ 仍然拒绝**。这正是"无一事件错误晋升 finalized"。
