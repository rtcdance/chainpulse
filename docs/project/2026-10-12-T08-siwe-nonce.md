# T08 交付：SIWE nonce 原子消费与地址绑定

> 对应任务：`docs/specs/2026-10-12-web3-go-backend-delivery-plan.md` §5 的 **T08 / P0 / 8h**。

> 其余访问边界（origin/URI/chain/version/time 严格校验、清理循环受 context 管理、operator RBAC、限流、错误脱敏）未做。

## 1. 缺陷

`pkg/siwe` 只有 `GenerateNonce` 与 `VerifySIWEWithOrigin`，**没有任何 nonce 存储**：调用方自己传 `nonceValidator func(string) bool`。因此：

- **没有原子性**：`nonceValidator` 是"检查"，删除/标记由调用方另行完成 ⇒ **check-then-act 窗口**（TOCTOU）。两个请求可以都观察到 nonce 有效。
- **没有地址绑定**：一个 nonce 只与自身绑定，不绑定"发给谁" ⇒ 拿到别人 nonce 的地址也能用。
- **没有共享存储**：多实例部署下各进程各有一份状态，天然无法保证"一次成功"。

T08 的验收正是："**同 nonce 两实例 100 并发只成功一次**"。

## 2. 实现

`pkg/siwe/nonce_store.go`（新）：

### 2.1 `NonceStore` 端口

```go
type NonceStore interface {
	Issue(ctx, address, nonce string, ttl time.Duration) error
	Consume(ctx, address, nonce string) (bool, error)
}
```

`Consume` **原子地**删除 nonce **当且仅当**它仍绑定到该地址。未知/已消费/过期/绑定他人**一律返回 `false` 而非错误** —— 调用方无法借错误区分"地址不对"与"已用过"。

### 2.2 两个实现

| 实现 | 适用 | 关键点 |
| --- | --- | --- |
| `MemoryNonceStore` | **单实例** | 互斥锁保护"读-删-比较"，**先删后比**：失败尝试也会**烧掉** nonce |
| `RedisNonceStore` | **多实例** | **Lua 脚本**在一次往返内完成 `GET` + `DEL` + 比较 |

Redis 脚本是核心：

```lua
local stored = redis.call('GET', KEYS[1])
if stored == false then return 0 end
redis.call('DEL', KEYS[1])
if stored == ARGV[1] then return 1 end
return 0
```

比较与删除分开写，正是本任务要关掉的 check-then-act 窗口。

**其他语义**：地址**大小写不敏感**（校验和格式与全小写视为同一地址）；`ttl` 由存储层强制；空地址/空 nonce/非正 ttl 一律拒绝。

## 3. 验收

### 3.1 真实 Redis：两实例 100 并发，**恰好一次成功**

`TestRedisNonceStoreTwoInstancesOneWinner` —— 两个 `RedisNonceStore` 实例共享同一 Redis，100 个 goroutine 同时 `Consume` 同一 nonce：

```
wins == 1   ✅
```

这是**进程内存储无法提供的性质**（独立进程不共享内存）。

### 3.2 其余（全部 PASS）

| 测试 | 断言 |
| --- | --- |
| `TestMemoryNonceStoreConcurrentConsumeHasOneWinner` | 进程内 100 并发 ⇒ **恰好 1 次成功** |
| `TestMemoryNonceStoreConsumeIsSingleUse` | 同一 nonce 第二次消费失败 |
| `TestMemoryNonceStoreBindsNonceToAddress` / `TestRedisNonceStoreBindsNonceToAddress` | **他人地址消费失败，且该失败会烧掉 nonce**（正确地址也无法重试） |
| `TestMemoryNonceStoreExpires` | 过期后不可消费 |
| `TestMemoryNonceStoreAddressCaseInsensitive` | 校验和/小写地址是同一绑定 |
| `TestMemoryNonceStoreRejectsBadInput` | 空地址/空 nonce/非正 ttl 拒绝 |
