## 4. 环境与工程陷阱（交接最大价值所在）

1. **GOPROXY 必须每次设置**：`export GOPROXY=https://goproxy.cn,direct`。本机 sumdb 不可达，纯净检出必失败。
2. **golangci-lint 必须用 ≥ 目标 Go 版本编译**：用 `$GOBIN/golangci-lint`（v2.12.2，go1.26.0）；brew 的 v2.8.0 会拒启动。`make lint` 自带 `--tests=false`。
3. **BSD grep 不支持 `\|` 交替**：多模式搜索**必须用 Grep 工具**。零命中型结论必须用第二个工具复核（§8.5/§8.6 两次被打脸）。
4. **本机 zsh 下 `sed -i ''` 不可靠**：批量改文件用 python。
5. **本机 macOS postgres 占环回 5432**，Docker 端口映射被压住：连本地容器库走 `cp-pg-fwd` 的 **15433**。
6. **迁移入口**：`go run ./cmd/migrate/ -db <dsn> -path migrations up`（migrations/ 目录，golang-migrate 风格，当前版本 13）。
7. **foundry 镜像 `ENTRYPOINT ["/bin/sh","-c"]`**：compose 里字符串 `command:` 会被拆词吞掉（只留第一个词）。必须 exec-form `entrypoint: ["/bin/sh","-c","anvil --host …"]`。`ANVIL_IP_ADDR` 环境变量是无效民间偏方，anvil 不读。
8. **compose 的 `--timestamp 0` 把 Anvil 钉死 Frontier**：EIP-1559 被拒、合约代码不入库。已删除。
9. **cast send 旗标顺序**：`--rpc-url`/`--private-key` 必须放在 `--create` **之前**（clap 位置参数截断）；anvil 容器内无 curl，外部用宿主机 `localhost:8545`（修复后可达）。
10. **手写 EVM 字节码验证不可靠**：RETURN 栈序（size 在顶）等细节极易错。用 SG 容器（`sg-fc-anvil`）的 forge 编译 DemoNFT，跨容器指向 `http://host.docker.internal:8545`。
11. **`go test -cpuprofile` 会在 cwd 留 `<pkg>.test` 二进制**：跑完删掉，否则 file-organization 门禁挡提交。
12. **`docs/` 被全局 gitignore**：提交文档必须 `git add -f`。提交后核验 `git show --stat` 确实包含文件。
13. **构建在 Docker 内**：`make build` 产物 = `build/bin/*`，可随时清空；不要手抄包清单（用 `make help`）。

## 5. 如何运行（常用命令）

```bash
# 门禁（每次提交前）
export GOPROXY=https://goproxy.cn,direct
go build ./... && go vet ./... && PATH="$HOME/Applications/workspace/goproject/bin:$PATH" make lint

# 部署演练（交叉编译 → docker build → 健康门禁 → 3 探针 → 报告；结束会拆容器）
bash scripts/acceptance/deploy-rehearsal.sh            # 报告写 build/acceptance/<sha12>/

# 长跑验证容器（演练脚本会 teardown，需手动起同 tag 镜像）
docker run -d --name cp-t12 --network docker_chainpulse-network \
  -e DATABASE_TYPE=postgres -e DATABASE_URL='postgres://chainpulse:chainpulse_dev@chainpulse-postgres:5432/chainpulse_dev?sslmode=disable' \
  -e CHAINS=ethereum -e CHAINPULSE_ETHEREUM_CHAIN_ID=1 \
  -e BLOCKCHAIN_NODE_URL=http://chainpulse-anvil-ethereum:8545 \
  -e REDIS_URL='redis://chainpulse-redis:6379' \
  -e LOG_LEVEL=info chainpulse:<sha12>

# T12 复现：forge 部署 + mint（在 sg-fc-anvil 容器里）
docker exec -w /contracts sg-fc-anvil forge create --rpc-url http://host.docker.internal:8545 \
  --private-key 0xac0974…f2ff80 src/DemoNFT.sol:DemoNFT --out /tmp/fc2-out --cache-path /tmp/fc2-cache --legacy --broadcast
docker exec sg-fc-anvil cast send --rpc-url http://host.docker.internal:8545 \
  --private-key 0xac0974…f2ff80 0x9fE46736679d2D9a65F0992F2272dE9f3c7fa6e0 "mint(address)" 0xf39F…92266 --legacy

# 验证落库
docker exec chainpulse-postgres psql -U chainpulse -d chainpulse_dev \
  -c "SELECT * FROM blockchain_events ORDER BY block_number DESC LIMIT 5;"
docker exec chainpulse-postgres psql -U chainpulse -d chainpulse_dev \
  -c "SELECT * FROM indexing_state;"
```

## 9. 风险与注意事项

- 镜像 digest 不可复现（连续 4 次构建 4 个 digest）—— 印证 §7.5 "永不 promote 一次 rebuild"；发布需 digest 记录 + 演练报告配对。
- 性能门禁在高负载宿主机上单次测量会假阻塞（±25% 波动，load≈15）；§8 的"复测一次"政策尚未实现进 gate。
