## Documentation Principles

1. **Concise**: <200 lines per doc (exceptions: API reference)
2. **Focused**: Single responsibility per file
3. **Current**: Archive outdated content
4. **Linked**: Cross-reference, don't duplicate
5. **Actionable**: Commands > theory
