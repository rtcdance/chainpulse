API 端点

核心概念 — Web3 实体到 Go 的映射

struct BlockchainEvent

链上事件在 Go 中是强类型结构体。每个 block/log 信息都是类型安全的字段，不会出现 undefined。

channel EventBus

Go 的 channel 天然支持发布-订阅模式，无需 Kafka。CSP 并发模型：ch <- event 发送，<-ch 接收。

big.Int 区块链数学

Solidity 的 uint256 在 Go 中用 *big.Int 表示，避免溢出。ConstantProductAMM 展示 AMM 恒定乘积公式。

context 超时与取消

每个 RPC 调用、数据库查询、HTTP 请求都携带 context.Context。到点了自动取消，不会泄漏 goroutine。

interface 插件系统

Logger、MetricsCollector、DatabasePlugin 都是接口，实现随时可替换，类似 Solidity 的接口与代理模式。

sync 并发安全

sync.RWMutex 保证读写安全，sync.Pool 复用对象，errgroup 并发编排 — Go 的标准库就够用。
