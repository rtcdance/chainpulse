## 开发环境设置

### 必需工具

```bash
# Go 环境
go version  # 需要 1.21+

# 消息队列
docker run -d --name kafka -p 9092:9092 confluentinc/cp-kafka:latest
docker run -d --name redis -p 6379:6379 redis:latest
docker run -d --name zeromq -p 5555:5555 zeromq/zeromq:latest

# 数据库
docker run -d --name postgres -p 5432:5432 -e POSTGRES_PASSWORD=password postgres:latest
docker run -d --name mongodb -p 27017:27017 mongo:latest

# 监控
docker run -d --name prometheus -p 9090:9090 prom/prometheus:latest
docker run -d --name grafana -p 3000:3000 grafana/grafana:latest
```

### 快速启动

```bash
# 启动所有服务
docker-compose -f docker/docker-compose.yml up -d

# 运行测试
go test ./pkg/plugins/mq/...
go test ./pkg/services/processing/...

# 运行集成测试
go test ./test/integration/...

# 运行性能测试
go test -bench=. ./test/integration/...
```
